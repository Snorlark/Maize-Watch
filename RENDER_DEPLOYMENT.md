# Maize-Watch Render Deployment Guide

## 🚀 Complete Deployment to Render.com

This guide will help you deploy your Maize-Watch IoT Agriculture Monitoring System to Render.com using a single Docker container with both backend and analytics services.

## 📋 Prerequisites

1. **Render Account**: Sign up at [render.com](https://render.com)
2. **GitHub Repository**: Your code should be in a GitHub repository
3. **MongoDB Atlas**: For production database (or use Render's MongoDB service)
4. **ThingSpeak Account**: For IoT data collection

## 🔧 Configuration Files Created

### 1. `render.yaml` - Render Service Configuration
- **Main App**: Docker container with Node.js + Python
- **MongoDB**: Database service
- **Redis**: Cache service

### 2. `Dockerfile` - Multi-service Container
- Node.js backend on port 3001
- Python analytics on port 8000
- Nginx reverse proxy on port 10000

### 3. `docker/mongodb.Dockerfile` - MongoDB Setup
- Pre-configured with collections and indexes

## 🚀 Deployment Steps

### Step 1: Prepare Your Repository

1. **Push all files to GitHub**:
```bash
git add .
git commit -m "Add Render deployment configuration"
git push origin main
```

### Step 2: Deploy to Render

1. **Go to [Render Dashboard](https://dashboard.render.com)**
2. **Click "New +" → "Blueprint"**
3. **Connect your GitHub repository**
4. **Select your repository**
5. **Render will automatically detect `render.yaml`**

### Step 3: Configure Environment Variables

In the Render dashboard, set these environment variables:

#### Required Variables:
```bash
# Database (Use MongoDB Atlas - Free tier available)
MONGO_URI=mongodb+srv://username:password@cluster.mongodb.net/maizewatch

# ThingSpeak (Get from your ThingSpeak account)
THINGSPEAK_CHANNEL_ID=3083651
THINGSPEAK_API_KEY=your_thingspeak_api_key

# Security (Auto-generated by Render)
JWT_SECRET=auto-generated
ENCRYPTION_KEY=auto-generated
```

#### Database Setup (MongoDB Atlas):
1. **Go to [MongoDB Atlas](https://cloud.mongodb.com)**
2. **Create a free cluster**
3. **Create a database user**
4. **Get your connection string**
5. **Update MONGO_URI in Render**

#### Optional Variables:
```bash
# Analytics Service URL (internal)
ANALYTICS_SERVICE_URL=http://localhost:8000

# Environment
NODE_ENV=production
FLASK_ENV=production
PYTHONUNBUFFERED=1

# Note: Redis is optional - app works without it
# REDIS_URL=optional-redis-url
```

### Step 4: Deploy

1. **Click "Apply"** in the Render dashboard
2. **Wait for deployment** (5-10 minutes)
3. **Check logs** for any errors

## 📊 Service Architecture

```
Internet
    ↓
Render Load Balancer
    ↓
Docker Container (Port 10000)
    ├── Nginx Reverse Proxy
    │   ├── /api/* → Backend (Port 3001)
    │   └── /analytics/* → Analytics (Port 8000)
    ├── Node.js Backend
    └── Python Analytics Service
    ↓
External Services
    ├── MongoDB Atlas
    ├── Redis Cache
    └── ThingSpeak IoT
```

## 🛠️ Troubleshooting

### Common Issues:

1. **Port Conflicts**:
   - Ensure all services use correct ports
   - Backend: 3001, Analytics: 8000, Nginx: 10000

2. **Database Connection**:
   - Check MongoDB URI format
   - Ensure database is accessible from Render

3. **Analytics Service**:
   - Check Python dependencies
   - Verify Flask app is running

4. **Environment Variables**:
   - Ensure all required variables are set
   - Check variable names match exactly

### Debug Commands:

```bash
# Check container logs
docker logs your-container-name

# Check service status
pm2 status

# Test internal services
curl http://localhost:3001/health  # Backend
curl http://localhost:8000/health  # Analytics
```
